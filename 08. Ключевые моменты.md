# 8. Ключевые моменты

1. S3 — объектное хранилище, не файловая система.
2. Объект состоит из данных, ключа и метаданных.
3. Ключ уникален внутри бакета.
4. Папки в S3 — логическая абстракция.
5. Минимальная единица доступа — объект.
6. Для локальной разработки удобно использовать MinIO.
7. В Python для работы с S3 чаще всего используют `boto3`.
8. Для файлов из запросов удобно использовать `upload_fileobj` или временные файлы.
9. Для приватных файлов используйте подписанные ссылки.
10. Пользовательские файлы всегда считаются недоверенными.
11. Проверяйте размер, расширение и фактический тип файла.
12. Храните файлы под случайными ключами.
13. В базе данных храните метаданные файла и ссылку на объект.
14. Отдавайте пользовательские файлы как вложения.
15. Для продакшена добавьте логирование, лимиты и, при необходимости, антивирус.
