# 7. Практические задания

Ниже — практические задания в формате, удобном для новичка. Сначала делаем минимальный рабочий сценарий, затем постепенно усложняем его.

## Что нужно установить перед началом

Для работы потребуется:

1. Python 3.10+.
2. Docker и Docker Compose.
3. Библиотеки:

```bash
pip install boto3 aioboto3 fastapi uvicorn python-dotenv
```

Если будете проверять MIME-тип по содержимому файла, дополнительно:

```bash
pip install python-magic
```

> Если у вас ещё нет Docker, сначала установите Docker Desktop или Docker Engine. Без него локальный MinIO запустить нельзя.

---

## Лабораторная работа 1. Запуск MinIO

Цель: научиться запускать локальное S3-хранилище.

### Шаги

1. Создайте файл `docker-compose.yml` со следующим содержимым:

```yaml
version: "3.9"

services:
  minio:
    image: quay.io/minio/minio:latest
    container_name: minio
    command: server /data --console-address ":9001"
    ports:
      - "9000:9000"
      - "9001:9001"
    environment:
      MINIO_ROOT_USER: minioadmin
      MINIO_ROOT_PASSWORD: minioadmin123
    volumes:
      - minio-data:/data

volumes:
  minio-data:
```

2. Запустите контейнер:

```bash
docker compose up -d
```

3. Откройте консоль MinIO: `http://localhost:9001`.
4. Войдите:
   - логин: `minioadmin`
   - пароль: `minioadmin123`
5. Создайте бакет `app-uploads`.
6. Загрузите в него любой файл вручную.
7. Проверьте, что он появился в списке объектов.
8. Попробуйте скачать этот файл через консоль.

### Результат

- MinIO запущен;
- бакет создан;
- файл виден в логике бакета;
- файл можно открыть и скачать.

## Лабораторная работа 2. Скрипт загрузки на Python

Цель: научиться работать с S3 API из Python.

### Шаги

1. Создайте файл `s3_demo.py`.
2. Установите `boto3`.
3. Подключитесь к MinIO:

```python
import boto3

client = boto3.client(
    "s3",
    endpoint_url="http://localhost:9000",
    aws_access_key_id="minioadmin",
    aws_secret_access_key="minioadmin123",
    region_name="us-east-1",
)
```

4. Проверьте, есть ли бакет:

```python
bucket = "app-uploads"

try:
    client.head_bucket(Bucket=bucket)
    print("Бакет существует")
except Exception:
    client.create_bucket(Bucket=bucket)
    print("Бакет создан")
```

5. Загрузите файл:

```python
client.upload_file(
    Filename="example.txt",
    Bucket=bucket,
    Key="demo/example.txt",
)
```

6. Выведите список объектов:

```python
response = client.list_objects_v2(Bucket=bucket)
for item in response.get("Contents", []):
    print(item["Key"], item["Size"])
```

7. Скачайте файл обратно:

```python
client.download_file(
    Bucket=bucket,
    Key="demo/example.txt",
    Filename="downloaded_example.txt",
)
```

8. Удалите файл:

```python
client.delete_object(Bucket=bucket, Key="demo/example.txt")
print("Файл удалён")
```

### Что важно понять

- `Bucket` — контейнер;
- `Key` — путь/имя объекта внутри бакета;
- `upload_file` загружает файл с диска;
- `download_file` скачивает файл на диск;
- `delete_object` удаляет конкретный объект.

### Результат

- скрипт работает без ошибок;
- объект создается и удаляется;
- итоговый сценарий понятен новичку.

## Лабораторная работа 3. Подписанные ссылки

Цель: научиться безопасно выдавать файл пользователю без давания доступа к самому бакету.

### Шаги

1. Сгенерируйте presigned URL:

```python
url = client.generate_presigned_url(
    ClientMethod="get_object",
    Params={
        "Bucket": "app-uploads",
        "Key": "demo/example.txt",
    },
    ExpiresIn=300,
)

print(url)
```

2. Откройте ссылку в браузере.
3. Проверьте, что она работает.
4. Подождите 5 минут и убедитесь, что ссылка перестала быть действительной.

### Важный комментарий

Подписанная ссылка — это не постоянный путь к файлу. Это временная ссылка, которая действует только определённое время, так безопаснее и удобнее для пользователя.

### Результат

- файл можно открыть по ссылке без логина в MinIO;
- ссылка имеет ограниченный срок жизни;
- доступ управляется через приложение, а не напрямую через бакет.

## Лабораторная работа 4. Интеграция с FastAPI

Цель: связать API и S3-хранилище.

### Шаги

1. Установите FastAPI и Uvicorn:

```bash
pip install fastapi uvicorn
```

2. Создайте минимальный API:

```python
from fastapi import FastAPI, UploadFile, File

app = FastAPI()


@app.post("/upload")
async def upload(file: UploadFile = File(...)):
    content = await file.read()
    return {
        "filename": file.filename,
        "size": len(content),
        "content_type": file.content_type,
    }
```

3. Подключите MinIO через `boto3`.
4. Принимайте файл из `UploadFile`.
5. Сохраняйте его в бакет через `upload_fileobj` или временный файл.
6. Возвращайте идентификатор файла или ключ хранения.
7. Добавьте маршрут `GET /files/{id}/download`, который генерирует presigned URL.

### Результат

- файл загружается через Swagger UI;
- файл сохраняется в MinIO;
- пользователь получает ссылку на скачивание.

## Лабораторная работа 5. Базовая защита загрузки

Цель: научиться не принимать «всё подряд».

### Задачи

1. Разрешить только расширения: `.pdf`, `.png`, `.jpg`, `.jpeg`.
2. Ограничить размер файла, например 10 MB.
3. Проверить MIME-тип по содержимому файла.
4. Генерировать случайный ключ объекта через `uuid4`.
5. Отдавать файл как вложение (`Content-Disposition: attachment`).

### Простой пример проверки

```python
from pathlib import Path

allowed = {".pdf", ".png", ".jpg", ".jpeg"}
filename = "report.pdf"
ext = Path(filename).suffix.lower()

if ext not in allowed:
    raise ValueError("Недопустимое расширение файла")
```

### Результат

- недопустимые файлы отклоняются;
- большие файлы не принимаются;
- имя файла не используется как ключ в хранилище;
- файлы отдаются как вложения.
