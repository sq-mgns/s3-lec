# 7. Практические задания

## Лабораторная работа 1. Запуск MinIO

Цель: научиться запускать локальное хранилище.

Задачи:

1. Запустить MinIO в Docker.
2. Открыть консоль.
3. Создать бакет `app-uploads`.
4. Загрузить файл вручную.
5. Скачать файл вручную.

Результат:

- бакет создан;
- файл виден в списке;
- файл можно скачать.

---

## Лабораторная работа 2. Скрипт загрузки на Python

Цель: научиться работать с S3 API из Python.

Задачи:

1. Установить `boto3`.
2. Подключиться к MinIO.
3. Создать бакет, если его нет.
4. Загрузить файл с диска.
5. Вывести список объектов.
6. Скачать файл обратно.
7. Удалить файл.

Результат:

- скрипт работает стабильно;
- объект создается и удаляется;
- ошибки обрабатываются.

---

## Лабораторная работа 3. Подписанные ссылки

Цель: освоить безопасную выдачу файлов.

Задачи:

1. Сгенерировать ссылку на скачивание.
2. Открыть ссылку в браузере.
3. Проверить, что через 5 минут ссылка перестает работать.
4. Проверить, что ссылка отдает файл как вложение.

Результат:

- пользователь может скачать файл без доступа к самому хранилищу;
- ссылка имеет ограниченный срок жизни.

---

## Лабораторная работа 4. Интеграция с FastAPI

Цель: связать API и хранилище.

Задачи:

1. Создать эндпоинт загрузки файла.
2. Принять файл через `UploadFile`.
3. Сохранить его во временный файл.
4. Посчитать размер и хеш.
5. Загрузить в MinIO.
6. Вернуть идентификатор файла.
7. Создать эндпоинт скачивания.

Результат:

- файл загружается через Swagger;
- файл сохраняется в MinIO;
- файл можно скачать по отдельному эндпоинту.

---

## Лабораторная работа 5. Базовая защита загрузки

Цель: сделать загрузку безопаснее.

Задачи:

1. Разрешить только `.pdf`, `.png`, `.jpg`, `.jpeg`.
2. Ограничить размер файла.
3. Добавить проверку фактического MIME-типа.
4. Генерировать ключ хранения через `uuid4`.
5. Отдавать файл с `Content-Disposition: attachment`.

Результат:

- недопустимые файлы отклоняются;
- большие файлы отклоняются;
- пользовательские имена не используются как ключи;
- файлы отдаются как вложения.

---

# Итог

Практика важнее теории. Каждый этап — от запуска MinIO до защищенной загрузки в FastAPI — помогает закрепить именно тот сценарий, который встречается в реальных проектах.
