# 4. Интеграция с FastAPI

## 4.1. Как файлы приходят в FastAPI

FastAPI поддерживает загрузку файлов через `UploadFile`.

Пример минимального эндпоинта:

```python
from fastapi import FastAPI, UploadFile, File

app = FastAPI()


@app.post("/upload")
async def upload_file(file: UploadFile = File(...)):
    return {
        "filename": file.filename,
        "content_type": file.content_type,
    }
```

Важно понимать:

- `file.filename` — имя файла, переданное клиентом;
- `file.content_type` — MIME-тип, заявленный клиентом;
- этим данным нельзя полностью доверять;
- для продакшена нужны проверки размера, типа и содержимого.

Материалы:

- [FastAPI Request Files](https://fastapi.tiangolo.com/tutorial/request-files/)
- [Starlette UploadFile](https://www.starlette.io/requests/#uploadfile)

---

## 4.2. Архитектура загрузки файлов

Хороший сценарий выглядит так:

1. Пользователь отправляет файл в API.
2. FastAPI принимает файл.
3. Приложение проверяет:
   - размер;
   - расширение;
   - фактический MIME-тип;
   - контрольную сумму;
   - при необходимости — антивирусом.
4. Приложение генерирует уникальный ключ объекта.
5. Файл сохраняется в S3/MinIO.
6. В базу данных записываются метаданные:
   - `id` файла;
   - `original_name`;
   - `storage_key`;
   - `content_type`;
   - `size`;
   - `sha256`;
   - `uploaded_by`;
   - `created_at`;
   - `status`.
7. Пользователю возвращается идентификатор файла.
8. Скачивание выполняется через отдельный эндпоинт, который выдает временную ссылку.

---

## 4.3. Рекомендуемая модель хранения метаданных

Не стоит полагаться только на metadata в S3.

Лучше хранить основную информацию в БД.

Пример таблицы `files`:

```text
id              UUID PRIMARY KEY
storage_key     TEXT NOT NULL
original_name   TEXT NOT NULL
content_type    TEXT NOT NULL
size            BIGINT NOT NULL
sha256          TEXT NOT NULL
uploaded_by     UUID NOT NULL
created_at      TIMESTAMP NOT NULL
status          TEXT NOT NULL
```

Почему так:

- по файлу можно строить поиск и отчеты;
- удобно управлять правами доступа;
- можно хранить статусы: `uploaded`, `scanning`, `ready`, `rejected`;
- можно реализовать аудит;
- не нужно дергать S3 ради базовой информации о файле.

## 4.4. Практический пример загрузки в FastAPI

Ниже учебный пример без авторизации и без реальной БД. В продакшене нужно добавить:

- аутентификацию;
- авторизацию;
- работу с БД;
- ограничение размера на уровне прокси;
- антивирусную проверку;
- нормальную обработку ошибок.

```python
import hashlib
import os
import tempfile
from pathlib import Path
from typing import Optional, Tuple
from uuid import uuid4

from fastapi import FastAPI, File, HTTPException, UploadFile
from fastapi.concurrency import run_in_threadpool
from fastapi.responses import RedirectResponse

import boto3
from botocore.config import Config
from botocore.exceptions import ClientError


app = FastAPI()


# -------------------------
# Конфигурация
# -------------------------

S3_ENDPOINT = os.getenv("S3_ENDPOINT", "http://localhost:9000")
S3_ACCESS_KEY = os.getenv("S3_ACCESS_KEY", "minioadmin")
S3_SECRET_KEY = os.getenv("S3_SECRET_KEY", "minioadmin123")
S3_REGION = os.getenv("S3_REGION", "us-east-1")
S3_BUCKET = os.getenv("S3_BUCKET", "app-uploads")

ALLOWED_EXTENSIONS = {".pdf", ".png", ".jpg", ".jpeg"}
ALLOWED_MIME_TYPES = {"application/pdf", "image/png", "image/jpeg"}
MAX_FILE_SIZE = 10 * 1024 * 1024  # 10 MB


# В учебном примере используем словарь вместо БД
FILES: dict[str, dict] = {}


# -------------------------
# S3 клиент
# -------------------------

def create_s3_client():
    return boto3.client(
        "s3",
        endpoint_url=S3_ENDPOINT,
        aws_access_key_id=S3_ACCESS_KEY,
        aws_secret_access_key=S3_SECRET_KEY,
        region_name=S3_REGION,
        config=Config(
            signature_version="s3v4",
            s3={"addressing_style": "path"},
        ),
    )


s3_client = create_s3_client()


def ensure_bucket(client, bucket_name: str) -> None:
    try:
        client.head_bucket(Bucket=bucket_name)
    except ClientError as exc:
        error_code = str(exc.response.get("Error", {}).get("Code", ""))
        if error_code in {"404", "NoSuchBucket"}:
            client.create_bucket(Bucket=bucket_name)
        else:
            raise


ensure_bucket(s3_client, S3_BUCKET)


# -------------------------
# Валидация и обработка
# -------------------------

def validate_extension(filename: Optional[str]) -> str:
    if not filename:
        raise HTTPException(status_code=400, detail="Имя файла не передано")

    extension = Path(filename).suffix.lower()

    if extension not in ALLOWED_EXTENSIONS:
        raise HTTPException(
            status_code=415,
            detail=f"Недопустимое расширение файла. Разрешены: {', '.join(ALLOWED_EXTENSIONS)}",
        )

    return extension


def detect_mime_type(file_path: str) -> Optional[str]:
    """
    Определяет MIME-тип по содержимому файла.
    Требует установки библиотеки python-magic.
    """
    try:
        import magic
    except ImportError:
        return None

    return magic.from_file(file_path, mime=True)


async def save_temp_file(
    upload_file: UploadFile,
    max_size: int,
) -> Tuple[str, int, str]:
    """
    Сохраняет загружаемый файл во временный файл,
    параллельно считает размер и SHA-256.
    """
    size = 0
    sha256 = hashlib.sha256()
    temp_path: Optional[str] = None

    try:
        with tempfile.NamedTemporaryFile(delete=False) as temp_file:
            temp_path = temp_file.name

            while True:
                chunk = await upload_file.read(1024 * 1024)

                if not chunk:
                    break

                size += len(chunk)

                if size > max_size:
                    raise HTTPException(
                        status_code=413,
                        detail="Файл превышает максимально допустимый размер",
                    )

                sha256.update(chunk)
                await run_in_threadpool(temp_file.write, chunk)

            await run_in_threadpool(temp_file.flush)

        return temp_path, size, sha256.hexdigest()

    except Exception:
        if temp_path and os.path.exists(temp_path):
            os.unlink(temp_path)
        raise


# -------------------------
# Presigned URL
# -------------------------

def create_presigned_get_url(
    bucket_name: str,
    object_key: str,
    expires_in: int = 300,
    download_name: Optional[str] = None,
) -> str:
    params = {
        "Bucket": bucket_name,
        "Key": object_key,
    }

    if download_name:
        ascii_name = (
            download_name
            .encode("ascii", "ignore")
            .decode("ascii")
            .replace('"', "")
            .replace("\\", "")
            .strip()
        ) or "download"

        from urllib.parse import quote
        utf8_name = quote(download_name, safe="")

        params["ResponseContentDisposition"] = (
            f'attachment; filename="{ascii_name}"; '
            f"filename*=UTF-8''{utf8_name}"
        )

    return s3_client.generate_presigned_url(
        ClientMethod="get_object",
        Params=params,
        ExpiresIn=expires_in,
        HttpMethod="GET",
    )


# -------------------------
# Эндпоинты
# -------------------------

@app.post("/files")
async def upload_file(file: UploadFile = File(...)):
    extension = validate_extension(file.filename)

    temp_path, size, sha256_digest = await save_temp_file(file, MAX_FILE_SIZE)

    try:
        detected_mime = detect_mime_type(temp_path)

        if detected_mime and detected_mime not in ALLOWED_MIME_TYPES:
            raise HTTPException(
                status_code=415,
                detail="Фактический тип файла не соответствует разрешенному",
            )

        content_type = detected_mime or "application/octet-stream"
        storage_key = f"uploads/{uuid4()}{extension}"

        await run_in_threadpool(
            s3_client.upload_file,
            temp_path,
            S3_BUCKET,
            storage_key,
            ExtraArgs={
                "ContentType": content_type,
                "Metadata": {
                    "sha256": sha256_digest,
                },
            },
        )

        file_id = str(uuid4())

        FILES[file_id] = {
            "key": storage_key,
            "size": size,
            "sha256": sha256_digest,
            "original_name": file.filename or "file",
            "content_type": content_type,
        }

        return {
            "id": file_id,
            "size": size,
            "sha256": sha256_digest,
            "storage_key": storage_key,
        }

    finally:
        if os.path.exists(temp_path):
            os.unlink(temp_path)


@app.get("/files/{file_id}/download")
async def download_file(file_id: str):
    file_meta = FILES.get(file_id)

    if not file_meta:
        raise HTTPException(status_code=404, detail="Файл не найден")

    url = create_presigned_get_url(
        bucket_name=S3_BUCKET,
        object_key=file_meta["key"],
        expires_in=300,
        download_name=file_meta["original_name"],
    )

    return RedirectResponse(url, status_code=307)
```

## 4.5. Пояснения к примеру

### Зачем нужен временный файл

Временный файл удобен, если нужно:

- проверить размер;
- посчитать хеш;
- проверить MIME-тип по содержимому;
- отправить файл на антивирусное сканирование;
- выполнить повторную загрузку в случае сбоя.

---

### Почему нельзя полностью доверять `Content-Type`

Потому что клиент может отправить:

```http
Content-Type: image/png
```

а по факту передать исполняемый файл или скрипт.

Поэтому для безопасности нужно проверять фактическое содержимое.

---

### Почему имя файла нужно хранить отдельно, а ключ генерировать заново

Никогда не используйте исходное имя пользователя как ключ хранения.

Плохо:

```text
uploads/report.pdf
```

Лучше:

```text
uploads/9f2f7f7a-3d1a-4e46-9a1e-3f9d0c1f2f3a.pdf
```

Причины:

- защита от подмены файлов;
- защита от коллизий;
- защита от path traversal;
- удобство аудита;
- предсказуемая структура хранения.

## 4.6. Асинхронность и блокирующие вызовы

`boto3` — синхронная библиотека. Если вызывать ее напрямую в async-функции, можно блокировать event loop.

Варианты:

1. Использовать `run_in_threadpool`:

```python
await run_in_threadpool(s3_client.upload_file, ...)
```

2. Использовать асинхронные аналоги, например `aioboto3`:

- [aioboto3 GitHub](https://github.com/terricain/aioboto3)

3. Использовать библиотеки-обертки для FastAPI, если они подходят проекту.

При выборе сторонней библиотеки проверяйте:

- активность проекта;
- версию;
- наличие тестов;
- совместимость с вашей версией FastAPI/Starlette;
- поддержку presigned URL;
- работу с MinIO;
- лицензию.

Полезно искать пакеты так:

- [PyPI search: fastapi async storages](https://pypi.org/search/?q=fastapi-async-storages)
- [GitHub search: fastapi async storages](https://github.com/search?q=fastapi-async-storages&type=repositories)

## 4.7. Ограничение размера запроса

Ограничение размера файла лучше контролировать на нескольких уровнях:

1. В коде приложения.
2. В веб-сервере или прокси.
3. В балансировщике нагрузки.

Например, для Nginx часто задают:

```nginx
client_max_body_size 10m;
```

Для продакшена одного только кода внутри приложения недостаточно.

## 4.8. Практика к этапу

Задание:

1. Поднимите FastAPI и MinIO.
2. Реализуйте эндпоинт `POST /files`.
3. Реализуйте эндпоинт `GET /files/{id}/download`.
4. Проверьте загрузку через Swagger UI: `http://localhost:8000/docs`.
5. Проверьте скачивание файла по временной ссылке.

Критерий готовности:

- файл загружается;
- файл сохраняется в MinIO;
- ссылка на скачивание работает;
- через 5 минут ссылка истекает;
- недопустимые расширения отклоняются;
- слишком большой файл отклоняется.

# Итог

FastAPI хорошо подходит для приема пользовательских файлов, но перед сохранением нужно выполнять проверки по размеру, типу и содержимому. В продакшене логика загрузки обычно включает приватный бакет, случайные ключи, запись метаданных в БД и выдачу временных подписанных ссылок.
