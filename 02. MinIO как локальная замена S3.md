# 2. MinIO как локальная замена S3

## 2.1. Что такое MinIO

MinIO — это S3-совместимое объектное хранилище.

Оно подходит для:

- локальной разработки;
- тестов;
- self-hosted окружений;
- CI/CD;
- эмуляции S3 без обращения к облаку.

Для разработчика это удобно: код может работать с локальным MinIO, а в продакшене — с AWS S3 или другим S3-совместимым хранилищем.

Важно: MinIO реализует S3 API, но не является полноценным AWS. Некоторые тонкости облачных сервисов AWS могут отличаться, но для базовой работы с объектами этого обычно достаточно.

Официальные материалы:

- [MinIO Documentation](https://min.io/docs/minio/linux/index.html)
- [MinIO Docker deployment](https://min.io/docs/minio/container/index.html)
- [MinIO Python SDK](https://min.io/docs/minio/linux/developers/python/minio-py.html)
- [MinIO Python client GitHub](https://github.com/minio/minio-py)

## 2.2. Быстрый запуск MinIO в Docker

Минимальный запуск:

```bash
docker run -d \
  --name minio \
  -p 9000:9000 \
  -p 9001:9001 \
  -e "MINIO_ROOT_USER=minioadmin" \
  -e "MINIO_ROOT_PASSWORD=minioadmin123" \
  -v minio-data:/data \
  quay.io/minio/minio server /data --console-address ":9001"
```

После запуска:

- S3 API доступен по адресу:

```text
http://localhost:9000
```

- веб-консоль доступна по адресу:

```text
http://localhost:9001
```

- логин:

```text
minioadmin
```

- пароль:

```text
minioadmin123
```

Каталог `/data` — это каталог хранения данных внутри контейнера. Том `minio-data` позволяет не терять данные после перезапуска контейнера.

---

## 2.3. Что делать после первого запуска

После запуска:

1. Откройте консоль MinIO: `http://localhost:9001`.
2. Войдите с учетными данными.
3. Создайте бакет, например:

```text
app-uploads
```

4. Загрузите туда любой тестовый файл.
5. Попробуйте скачать его через консоль.
6. Проверьте, что объект появился в бакете.

Это минимальная ручная практика, которая помогает понять, как выглядит объект, ключ и метаданные.

## 2.4. Запуск через Docker Compose

Пример `docker-compose.yml`:

```yaml
version: "3.9"

services:
  minio:
    image: quay.io/minio/minio:latest
    container_name: minio
    command: server /data --console-address ":9001"
    ports:
      - "9000:9000"
      - "9001:9001"
    environment:
      MINIO_ROOT_USER: minioadmin
      MINIO_ROOT_PASSWORD: minioadmin123
    volumes:
      - minio-data:/data
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:9000/minio/health/live"]
      interval: 10s
      timeout: 5s
      retries: 5

volumes:
  minio-data:
```

Запуск:

```bash
docker compose up -d
```

## 2.5. Утилита `mc`

`mc` — это официальный клиент командной строки MinIO.

Пример настройки:

```bash
mc alias set local http://localhost:9000 minioadmin minioadmin123
```

Создать бакет:

```bash
mc mb local/app-uploads
```

Загрузить файл:

```bash
mc cp test.pdf local/app-uploads/test.pdf
```

Посмотреть объекты:

```bash
mc ls local/app-uploads
```

Удалить объект:

```bash
mc rm local/app-uploads/test.pdf
```

Материалы:

- [MinIO Client reference](https://min.io/docs/minio/linux/reference/minio-mc.html)

## 2.6. Частые ошибки при работе с MinIO

### Ошибка 1: неверный `endpoint_url`

Для локального MinIO нужно указывать адрес S3 API:

```text
http://localhost:9000
```

Не нужно указывать адрес консоли:

```text
http://localhost:9001
```

Консоль — это интерфейс управления, а не S3 API endpoint.

---

### Ошибка 2: неправильные креды

Если вы задали переменные окружения:

```yaml
MINIO_ROOT_USER: minioadmin
MINIO_ROOT_PASSWORD: minioadmin123
```

то в коде нужно использовать именно их.

---

### Ошибка 3: неверный стиль адресации

Для AWS часто используется виртуальный стиль:

```text
https://bucket-name.s3.region.amazonaws.com/key
```

Для локального MinIO часто удобнее path-style:

```text
http://localhost:9000/bucket-name/key
```

В `boto3` это настраивается через конфигурацию.

---

### Ошибка 4: подписанная ссылка указывает на внутренний адрес

Если сервер генерирует pre-signed URL как:

```text
http://minio:9000/...
```

а браузер пользователя не имеет доступа к внутреннему имени `minio`, ссылка не откроется.

Решение:

- генерировать подписанные ссылки через публично доступный адрес;
- использовать reverse proxy;
- передавать правильный `endpoint_url` для публичного доступа.

---

# Итог

MinIO — удобная локальная реализация S3 API. Он позволяет разрабатывать и тестировать работу с объектным хранилищем без облачного провайдера, а затем легко переключиться на AWS S3 или другой совместимый сервис.
