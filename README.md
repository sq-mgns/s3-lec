# S3 / MinIO для разработчиков

Небольшой учебный репозиторий по объектному хранилищу S3, локальному MinIO и работе с файлами через Python, FastAPI и boto3/aioboto3.

Содержит:
- базовую теорию про S3, бакеты и ключи объектов;
- запуск MinIO локально;
- примеры загрузки, скачивания и удаления файлов;
- генерацию временных presigned URL;
- интеграцию с FastAPI;
- базовые меры безопасности при работе с пользовательскими файлами.

Подходит для начинающих разработчиков, которые хотят быстро понять, как устроено хранение файлов в S3 и как использовать его в проекте.
