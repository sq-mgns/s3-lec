# 3. Работа с S3/MinIO из Python через boto3 и aioboto3

## 3.1. Что такое boto3

`boto3` — это официальный AWS SDK для Python. Он позволяет работать с S3, DynamoDB, SQS, SNS, IAM и другими сервисами AWS. Для нас важно то, что `boto3` умеет читать и записывать объекты в S3 и MinIO.

### Установка

```bash
pip install boto3
```

### Когда использовать `boto3`

Используйте `boto3`, если:

- ваш код синхронный;
- вы не работаете в async-эндпоинтах FastAPI;
- вам нужна простая и понятная схема без дополнительной асинхронной обвязки;
- вы пишете скрипт, CLI, cron-задачу или сервисный код.

---

## 3.2. Что такое aioboto3

`aioboto3` — это асинхронная версия `boto3`. Её удобно использовать в FastAPI, когда вы хотите не блокировать event loop во время обращений к S3.

### Установка

```bash
pip install aioboto3
```

### Когда использовать `aioboto3`

Используйте `aioboto3`, если:

- вы работаете в async FastAPI;
- обращаетесь к S3 из нескольких запросов параллельно;
- важно избежать блокировок на I/O;
- вы хотите сделать код более «асинхронным» по архитектуре.

### Простое правило

- для простого учебного проекта и скриптов чаще выбирают `boto3`;
- для FastAPI/async-сервиса лучше рассматривать `aioboto3`.

---

## 3.3. Клиент или ресурс

У `boto3` и `aioboto3` есть похожие подходы.

### Синхронный вариант

```python
import boto3

client = boto3.client("s3")
```

### Асинхронный вариант

```python
import aioboto3

session = aioboto3.Session()

async def get_client():
    async with session.client("s3") as client:
        return client
```

Для начинающих обычно проще начать с `boto3`, а затем перейти к `aioboto3`, когда уже появится понимание, что именно нужно от асинхронного I/O.

---

## 3.4. Создание клиента для MinIO

### Синхронный вариант через `boto3`

```python
import os
from typing import Optional

import boto3
from botocore.config import Config


def create_s3_client(
    endpoint_url: Optional[str] = None,
    access_key: Optional[str] = None,
    secret_key: Optional[str] = None,
    region: str = "us-east-1",
    addressing_style: str = "path",
):
    return boto3.client(
        "s3",
        endpoint_url=endpoint_url,
        aws_access_key_id=access_key,
        aws_secret_access_key=secret_key,
        region_name=region,
        config=Config(
            signature_version="s3v4",
            s3={"addressing_style": addressing_style},
        ),
    )
```

Пример использования:

```python
client = create_s3_client(
    endpoint_url="http://localhost:9000",
    access_key="minioadmin",
    secret_key="minioadmin123",
    region="us-east-1",
    addressing_style="path",
)
```

Пояснения:

- `endpoint_url` — адрес S3 API;
- `signature_version="s3v4"` — современный механизм подписи запросов;
- `addressing_style="path"` — удобно для локального MinIO;
- в AWS часто используют `virtual` или оставляют поведение по умолчанию.

## 3.5. Асинхронный вариант через `aioboto3`

```python
import os

import aioboto3
from botocore.config import Config


async def create_async_s3_client():
    session = aioboto3.Session()

    return session.client(
        "s3",
        endpoint_url=os.getenv("S3_ENDPOINT", "http://localhost:9000"),
        aws_access_key_id=os.getenv("S3_ACCESS_KEY", "minioadmin"),
        aws_secret_access_key=os.getenv("S3_SECRET_KEY", "minioadmin123"),
        region_name=os.getenv("S3_REGION", "us-east-1"),
        config=Config(
            signature_version="s3v4",
            s3={"addressing_style": "path"},
        ),
    )
```

### Использование

```python
async def upload_file_async():
    client = await create_async_s3_client()
    async with client:
        await client.put_object(
            Bucket="app-uploads",
            Key="demo/file.txt",
            Body=b"hello from async s3",
        )
```

> Важно: `aioboto3` работает через асинхронный контекст и методы, похожие на `boto3`, но их нужно вызывать асинхронно.

## 3.7. Создание бакета

Перед загрузкой объектов бакет должен существовать.

### Синхронный пример

```python
from botocore.exceptions import ClientError


def ensure_bucket(client, bucket_name: str) -> bool:
    try:
        client.head_bucket(Bucket=bucket_name)
        return False
    except ClientError as exc:
        error_code = str(exc.response.get("Error", {}).get("Code", ""))
        if error_code in {"404", "NoSuchBucket"}:
            client.create_bucket(Bucket=bucket_name)
            return True
        raise
```

### Асинхронный пример

```python
from botocore.exceptions import ClientError


async def ensure_bucket_async(client, bucket_name: str) -> bool:
    try:
        await client.head_bucket(Bucket=bucket_name)
        return False
    except ClientError as exc:
        error_code = str(exc.response.get("Error", {}).get("Code", ""))
        if error_code in {"404", "NoSuchBucket"}:
            await client.create_bucket(Bucket=bucket_name)
            return True
        raise
```

## 3.8. Загрузка файла с диска

### Синхронно через `boto3`

```python
def upload_local_file(
    client,
    bucket_name: str,
    file_path: str,
    object_key: str,
    content_type: str | None = None,
    metadata: dict[str, str] | None = None,
) -> str:
    extra_args = {}

    if content_type:
        extra_args["ContentType"] = content_type

    if metadata:
        extra_args["Metadata"] = metadata

    client.upload_file(
        Filename=file_path,
        Bucket=bucket_name,
        Key=object_key,
        ExtraArgs=extra_args or None,
    )

    return object_key
```

### Асинхронно через `aioboto3`

```python
async def upload_local_file_async(client, bucket_name: str, file_path: str, object_key: str):
    with open(file_path, "rb") as file:
        body = file.read()

    await client.put_object(
        Bucket=bucket_name,
        Key=object_key,
        Body=body,
        ContentType="application/pdf",
    )
```

## 3.9. Загрузка файлового объекта

### Синхронно

```python
def upload_file_object(
    client,
    bucket_name: str,
    fileobj,
    object_key: str,
    content_type: str | None = None,
    metadata: dict[str, str] | None = None,
) -> str:
    extra_args = {}

    if content_type:
        extra_args["ContentType"] = content_type

    if metadata:
        extra_args["Metadata"] = metadata

    if hasattr(fileobj, "seek"):
        fileobj.seek(0)

    client.upload_fileobj(
        Fileobj=fileobj,
        Bucket=bucket_name,
        Key=object_key,
        ExtraArgs=extra_args or None,
    )

    return object_key
```

### Асинхронно

```python
async def upload_fileobj_async(client, bucket_name: str, fileobj, object_key: str):
    content = await fileobj.read()

    await client.put_object(
        Bucket=bucket_name,
        Key=object_key,
        Body=content,
    )
```

## 3.12. Подписанные ссылки

```python
from urllib.parse import quote


def create_presigned_get_url(
    client,
    bucket_name: str,
    object_key: str,
    expires_in: int = 300,
    download_name: str | None = None,
) -> str:
    params = {
        "Bucket": bucket_name,
        "Key": object_key,
    }

    if download_name:
        ascii_name = (
            download_name
            .encode("ascii", "ignore")
            .decode("ascii")
            .replace('"', "")
            .replace("\\", "")
            .strip()
        ) or "download"

        utf8_name = quote(download_name, safe="")

        params["ResponseContentDisposition"] = (
            f'attachment; filename="{ascii_name}"; '
            f"filename*=UTF-8''{utf8_name}"
        )

    return client.generate_presigned_url(
        ClientMethod="get_object",
        Params=params,
        ExpiresIn=expires_in,
        HttpMethod="GET",
    )
```

Для FastAPI и async-кода это обычно вызывается не напрямую в request-обработчике, а в отдельной функции-сервисе, чтобы не нагружать event loop.

## 3.13. Какой вариант выбрать

### Выбирайте `boto3`, если:

- вы учитесь;
- пишете скрипты и утилиты;
- вам нужно быстро решить задачу;
- сервис не является интенсивным по I/O.

### Выбирайте `aioboto3`, если:

- вы пишете async FastAPI;
- у вас много параллельных веб-запросов;
- важна производительность и отсутствие блокировок.

### Рекомендуемый путь новичка

1. Освоить `boto3` на простых примерах.
2. Запустить MinIO и сделать загрузку/скачивание.
3. Потом перейти на `aioboto3` в FastAPI, когда появляется контракт API и архитектура сервиса.

## 3.12. Pre-signed URL — временные ссылки

### Зачем это нужно

Если файл хранится в приватном бакете, нельзя просто отдать пользователю публичную ссылку.

Вместо этого можно сгенерировать временную подписанную ссылку.

Такая ссылка:

- разрешает доступ к конкретному объекту;
- работает ограниченное время;
- не требует от пользователя логина в S3;
- не раскрывает credentials;
- подходит для выдачи файлов из приложения.

---

### Генерация ссылки на скачивание

```python
from urllib.parse import quote


def create_presigned_get_url(
    client,
    bucket_name: str,
    object_key: str,
    expires_in: int = 300,
    download_name: str | None = None,
) -> str:
    params = {
        "Bucket": bucket_name,
        "Key": object_key,
    }

    if download_name:
        ascii_name = (
            download_name
            .encode("ascii", "ignore")
            .decode("ascii")
            .replace('"', "")
            .replace("\\", "")
            .strip()
        ) or "download"

        utf8_name = quote(download_name, safe="")

        params["ResponseContentDisposition"] = (
            f'attachment; filename="{ascii_name}"; '
            f"filename*=UTF-8''{utf8_name}"
        )

    return client.generate_presigned_url(
        ClientMethod="get_object",
        Params=params,
        ExpiresIn=expires_in,
        HttpMethod="GET",
    )
```

Пример:

```python
url = create_presigned_get_url(
    client=client,
    bucket_name="app-uploads",
    object_key="documents/report.pdf",
    expires_in=300,
    download_name="Отчет за февраль.pdf",
)

print(url)
```

Что важно:

- `expires_in` задается в секундах;
- `300` — 5 минут;
- для скачивания лучше использовать `ResponseContentDisposition: attachment`;
- если отдаете потенциально опасные файлы, лучше принудительно отдавать их как вложение.

Дополнительно:

- [Boto3 presigned URL guide](https://boto3.amazonaws.com/v1/documentation/api/latest/guide/s3-presigned-url.html)
- [AWS presigned URL docs](https://docs.aws.amazon.com/AmazonS3/latest/userguide/ShareObjectPreSignedURL.html)

## 3.13. Обработка ошибок

Всегда обрабатывайте ошибки `ClientError`.

```python
from botocore.exceptions import ClientError


def safe_upload_file(client, bucket_name: str, file_path: str, key: str):
    try:
        client.upload_file(
            Filename=file_path,
            Bucket=bucket_name,
            Key=key,
        )
        return True
    except ClientError as exc:
        error_code = exc.response.get("Error", {}).get("Code")
        error_message = exc.response.get("Error", {}).get("Message")
        print(f"S3 upload failed: {error_code} - {error_message}")
        return False
```
