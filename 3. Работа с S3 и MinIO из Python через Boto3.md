# 3. Работа с S3/MinIO из Python через Boto3

## 3.1. Что такое Boto3

Boto3 — официальная библиотека AWS SDK для Python.

Она позволяет работать с:

- S3;
- DynamoDB;
- SQS;
- SNS;
- IAM;
- и другими сервисами.

Для нас ключевой сервис — `s3`.

Материалы:

- [Boto3 documentation](https://boto3.amazonaws.com/v1/documentation/api/latest/index.html)
- [Boto3 S3 uploading files](https://boto3.amazonaws.com/v1/documentation/api/latest/guide/s3-uploading-files.html)
- [Boto3 S3 presigned URLs](https://boto3.amazonaws.com/v1/documentation/api/latest/guide/s3-presigned-url.html)
- [Boto3 S3 client reference](https://boto3.amazonaws.com/v1/documentation/api/latest/reference/services/s3.html)

Установка:

```bash
pip install boto3
```

## 3.2. Клиент или ресурс

В `boto3` есть два основных стиля работы:

1. Низкоуровневый клиент:

```python
client = boto3.client("s3")
```

2. Ресурсный интерфейс:

```python
s3 = boto3.resource("s3")
```

Для проектов чаще удобнее клиент, потому что он:

- более явный;
- ближе к S3 API;
- удобен для генерации подписанных ссылок;
- стабильнее воспринимается в сервисном коде.

В дальнейшем будем использовать клиент.

## 3.3. Создание клиента для MinIO

Пример фабричного метода:

```python
import os
from typing import Optional

import boto3
from botocore.config import Config


def create_s3_client(
    endpoint_url: Optional[str] = None,
    access_key: Optional[str] = None,
    secret_key: Optional[str] = None,
    region: str = "us-east-1",
    addressing_style: str = "path",
):
    return boto3.client(
        "s3",
        endpoint_url=endpoint_url,
        aws_access_key_id=access_key,
        aws_secret_access_key=secret_key,
        region_name=region,
        config=Config(
            signature_version="s3v4",
            s3={"addressing_style": addressing_style},
        ),
    )
```

Пример использования:

```python
client = create_s3_client(
    endpoint_url="http://localhost:9000",
    access_key="minioadmin",
    secret_key="minioadmin123",
    region="us-east-1",
    addressing_style="path",
)
```

Пояснения:

- `endpoint_url` — адрес S3 API;
- `signature_version="s3v4"` — современный механизм подписи запросов;
- `addressing_style="path"` — удобно для локального MinIO;
- в AWS часто используют `virtual` или оставляют поведение по умолчанию.

## 3.5. Создание бакета

Перед загрузкой объектов бакет должен существовать.

Пример функции:

```python
from botocore.exceptions import ClientError


def ensure_bucket(client, bucket_name: str) -> bool:
    """
    Возвращает True, если бакет был создан,
    и False, если он уже существовал.
    """
    try:
        client.head_bucket(Bucket=bucket_name)
        return False
    except ClientError as exc:
        error_code = str(exc.response.get("Error", {}).get("Code", ""))
        if error_code in {"404", "NoSuchBucket"}:
            client.create_bucket(Bucket=bucket_name)
            return True
        raise
```

Использование:

```python
ensure_bucket(client, "app-uploads")
```

Важно:

- в AWS при создании бакета в регионе, отличном от `us-east-1`, может потребоваться `CreateBucketConfiguration`;
- для локального MinIO обычно достаточно простого вызова `create_bucket`.

## 3.6. Загрузка файла с диска

Метод `upload_file` подходит, если файл уже лежит на диске.

```python
def upload_local_file(
    client,
    bucket_name: str,
    file_path: str,
    object_key: str,
    content_type: str | None = None,
    metadata: dict[str, str] | None = None,
) -> str:
    extra_args = {}

    if content_type:
        extra_args["ContentType"] = content_type

    if metadata:
        extra_args["Metadata"] = metadata

    client.upload_file(
        Filename=file_path,
        Bucket=bucket_name,
        Key=object_key,
        ExtraArgs=extra_args or None,
    )

    return object_key
```

Пример:

```python
upload_local_file(
    client=client,
    bucket_name="app-uploads",
    file_path="report.pdf",
    object_key="documents/report.pdf",
    content_type="application/pdf",
    metadata={"source": "manual-upload"},
)
```

## 3.7. Загрузка файлового объекта

Метод `upload_fileobj` полезен, если файл уже открыт как объект или вы получаете его из FastAPI.

```python
def upload_file_object(
    client,
    bucket_name: str,
    fileobj,
    object_key: str,
    content_type: str | None = None,
    metadata: dict[str, str] | None = None,
) -> str:
    extra_args = {}

    if content_type:
        extra_args["ContentType"] = content_type

    if metadata:
        extra_args["Metadata"] = metadata

    if hasattr(fileobj, "seek"):
        fileobj.seek(0)

    client.upload_fileobj(
        Fileobj=fileobj,
        Bucket=bucket_name,
        Key=object_key,
        ExtraArgs=extra_args or None,
    )

    return object_key
```

## 3.9. Получение объекта в память

Иногда нужно не сохранять файл на диск, а получить поток байтов.

```python
def get_object_bytes(client, bucket_name: str, object_key: str) -> bytes:
    response = client.get_object(
        Bucket=bucket_name,
        Key=object_key,
    )
    return response["Body"].read()
```

Важно:

- для больших файлов лучше использовать потоковую обработку;
- не читайте большие файлы целиком в память без необходимости.

## 3.12. Pre-signed URL — временные ссылки

### Зачем это нужно

Если файл хранится в приватном бакете, нельзя просто отдать пользователю публичную ссылку.

Вместо этого можно сгенерировать временную подписанную ссылку.

Такая ссылка:

- разрешает доступ к конкретному объекту;
- работает ограниченное время;
- не требует от пользователя логина в S3;
- не раскрывает credentials;
- подходит для выдачи файлов из приложения.

---

### Генерация ссылки на скачивание

```python
from urllib.parse import quote


def create_presigned_get_url(
    client,
    bucket_name: str,
    object_key: str,
    expires_in: int = 300,
    download_name: str | None = None,
) -> str:
    params = {
        "Bucket": bucket_name,
        "Key": object_key,
    }

    if download_name:
        ascii_name = (
            download_name
            .encode("ascii", "ignore")
            .decode("ascii")
            .replace('"', "")
            .replace("\\", "")
            .strip()
        ) or "download"

        utf8_name = quote(download_name, safe="")

        params["ResponseContentDisposition"] = (
            f'attachment; filename="{ascii_name}"; '
            f"filename*=UTF-8''{utf8_name}"
        )

    return client.generate_presigned_url(
        ClientMethod="get_object",
        Params=params,
        ExpiresIn=expires_in,
        HttpMethod="GET",
    )
```

Пример:

```python
url = create_presigned_get_url(
    client=client,
    bucket_name="app-uploads",
    object_key="documents/report.pdf",
    expires_in=300,
    download_name="Отчет за февраль.pdf",
)

print(url)
```

Что важно:

- `expires_in` задается в секундах;
- `300` — 5 минут;
- для скачивания лучше использовать `ResponseContentDisposition: attachment`;
- если отдаете потенциально опасные файлы, лучше принудительно отдавать их как вложение.

Дополнительно:

- [Boto3 presigned URL guide](https://boto3.amazonaws.com/v1/documentation/api/latest/guide/s3-presigned-url.html)
- [AWS presigned URL docs](https://docs.aws.amazon.com/AmazonS3/latest/userguide/ShareObjectPreSignedURL.html)

## 3.13. Обработка ошибок

Всегда обрабатывайте ошибки `ClientError`.

```python
from botocore.exceptions import ClientError


def safe_upload_file(client, bucket_name: str, file_path: str, key: str):
    try:
        client.upload_file(
            Filename=file_path,
            Bucket=bucket_name,
            Key=key,
        )
        return True
    except ClientError as exc:
        error_code = exc.response.get("Error", {}).get("Code")
        error_message = exc.response.get("Error", {}).get("Message")
        print(f"S3 upload failed: {error_code} - {error_message}")
        return False
```
